# Snow CLI User Documentation - Proxy and Browser Settings

Welcome to Snow CLI! Agentic coding in your terminal.

## Proxy and Browser Settings

- When proxy is enabled, CLI traffic will be transmitted through the custom port

- Browser Settings: The CLI's web search functionality will use a browser. By default, it auto-detects the system browser (Windows/macOS/Linux).
- **Windows auto-detect priority: Chrome > Edge** (Chrome is the most common install and avoids Edge's known Alt+Tab "phantom window" residue after web search; falls back to Edge when Chrome is absent). macOS prefers Chrome; Linux probes `google-chrome` → `chromium` → `chromium-browser` → `microsoft-edge`.
- To pin a specific browser, or if the default browser moved to a non-standard location (or Linux lacks Chromium/Chrome), set the executable path manually.
- The common error `Failed to launch the browser process` usually means the browser is not installed or has missing dependencies. Install `chromium` or `google-chrome` first, then fill in the executable path in settings.
- Config file: `~/.snow/proxy-config.json` — set `browserPath` manually.

## Windows known issue: "phantom windows" in Alt+Tab after web search

- **Symptom**: On Windows, after using the default web connectivity features (web search / page fetch), an extra "web search" entry appears in `Alt+Tab` that can neither be opened nor closed.
- **Cause**: A known, unfixed Edge browser issue. Web search works by creating a transparent browser window; even after the search finishes and the browser is closed, the window handle lingers in the system's window list.
- **Solution (recommended, system setting)**:

  1. Open `Settings` → `System` → `Multitasking`
  2. Find "Show tabs from apps when snapping or pressing Alt+Tab"
  3. Choose `Don't show tabs`

  This does not affect multitasking at all — it actually keeps the task switcher cleaner by hiding lingering Edge window handles from Alt+Tab.

- **Alternative (CLI sweep)**: run `snow --sweep-phantom-windows` to actively destroy orphaned Chromium/Edge window handles (Windows only; only windows owned by exited processes are touched, so running browsers are never affected). If entries still remain after sweeping, restart Explorer (Task Manager → Windows Explorer → Restart).
