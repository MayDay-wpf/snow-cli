# Snow CLI 使用文档——MCP 配置

欢迎使用 Snow CLI！在终端中进行 Agentic 编程。

## MCP 配置

MCP（Model Context Protocol）是一个开放协议，允许 AI 助手与外部工具和服务集成。Snow CLI 支持配置和管理 MCP 服务。

### 什么是 MCP

MCP（Model Context Protocol）是一种标准化协议，用于连接 AI 助手与各种外部工具、数据源和服务。通过 MCP，Snow CLI 可以访问本地文件系统、连接数据库、调用外部 API 等。

### 查看 MCP 服务状态

在对话界面输入 `/mcp` 指令可以查看所有 MCP 服务的状态：

**显示内容**：

- 服务名称
- 连接状态（绿色 ● 表示已连接，红色 ● 表示连接失败，灰色 ● 表示已禁用）
- 服务类型（System/External/Disabled）
- 可用工具列表

**操作方式**：

- **上下箭头**：在服务列表中导航
- **回车键**：重新连接选中的服务
- **Tab 键**：切换外部服务的启用/禁用状态（内置服务不支持）
- 选择 "Refresh all services" 选项可刷新所有服务

### 配置 MCP 服务

#### 1. 进入配置界面

在主菜单中选择 `MCP Configuration` 进入 MCP 配置编辑器。

进入后会先选择配置范围（Scope）：

- **项目级配置**：写入当前工作目录下的 `.snow/settings.json`（`mcpServers` 字段）
- **全局配置**：写入用户目录下的 `~/.snow/settings.json`（`mcpServers` 字段）

#### 2. 自动打开编辑器

系统会自动检测并使用合适的文本编辑器打开配置草稿文件；保存后会写回对应 scope 的 `settings.json`：

**编辑器优先级**：

1. 环境变量 `VISUAL` 指定的编辑器
2. 环境变量 `EDITOR` 指定的编辑器
3. 系统默认编辑器

**Windows 系统**：检测顺序为 notepad++ > notepad > code > vim > nano

**macOS/Linux 系统**：检测顺序为 nano > vim > vi

**设置默认编辑器**：

macOS/Linux:

```bash
export EDITOR=nano
```

Windows:

```cmd
set EDITOR=notepad
```

#### 3. 配置文件位置与优先级

MCP 配置统一存放在 `settings.json` 的 `mcpServers` 字段中，不再使用独立的 `mcp-config.json`（旧文件会在启动时迁移）。

| 范围   | 路径                            | 作用域     |
| ------ | ------------------------------- | ---------- |
| 项目级 | `<project>/.snow/settings.json` | 仅当前项目 |
| 全局   | `~/.snow/settings.json`         | 所有项目   |

**合并规则**：

- 运行时会合并全局与项目级配置
- **项目级优先**：同名服务以项目级配置为准
- 适合把仅当前仓库需要的 MCP 放在项目级，把通用 MCP 放在全局

你也可以直接手写编辑这两个文件，不必经过 UI。

#### 4. 配置文件格式

**配置文件结构**（项目级 / 全局相同）：

```json
{
	"mcpServers": {
		"服务名称": {
			"command": "命令",
			"args": ["参数1", "参数2"],
			"enabled": true
		}
	}
}
```

> **注意**：`settings.json` 里还可能有其他项目设置（如 `yoloMode`、`disabledSkills`）。新增 MCP 时请先读取现有文件，再**合并**写入 `mcpServers`，不要覆盖整个文件。

**配置项说明**：

- `mcpServers`：MCP 服务配置对象
- `服务名称`：自定义的服务名称（唯一标识）
- `type`：传输类型，可选值为 `'stdio'`、`'local'`、`'http'`、`'sse'` 或 `'api'`（可选，默认为根据 `url` 或 `command` 自动推断）
  - `'stdio'`：本地子进程通信（STDIO 模式）
  - `'local'`：`'stdio'` 的别名，功能完全相同
  - `'http'`：HTTP 模式，用于连接远程 MCP 服务
  - `'sse'`：SSE 模式（同样通过 HTTP 传输，兼容旧版 SSE 服务）
  - `'api'`：自定义 API 模式，把普通 HTTP 接口映射为 MCP 工具（与 Snow APP 的「API」类型 MCP 配置完全兼容）
- `command`：启动 MCP 服务的命令（`stdio`/`local` 类型必需）
- `args`：命令参数数组（可选；`api` 类型可放 `{cookies, endpoints}` 规格对象，用于兼容 Snow APP 数据库格式）
- `url`：MCP 服务端点 URL（`http` 类型必需；`api` 类型为 Base URL）
- `headers`：HTTP 请求头配置（`http` / `api` 类型可选）
- `cookies`：公共 Cookie（可选，仅 `api` 类型）
- `endpoints`：接口定义数组（`api` 类型必需，每个接口会成为一个 MCP 工具）
- `enabled`：是否启用该服务（可选，默认为 true）
- `timeout`：工具调用超时时间，单位毫秒（可选，默认为 1200000，即 20 分钟）
- `env` / `environment`：环境变量配置（可选），`environment` 是 `env` 的别名

**配置示例**：

**项目级配置示例**（`<project>/.snow/settings.json`）：

```json
{
	"yoloMode": false,
	"mcpServers": {
		"project-docs": {
			"type": "stdio",
			"command": "npx",
			"args": ["-y", "@modelcontextprotocol/server-filesystem", "./docs"],
			"enabled": true
		}
	}
}
```

**STDIO/Local 模式示例**：

```json
{
	"mcpServers": {
		"filesystem": {
			"type": "stdio",
			"command": "npx",
			"args": [
				"-y",
				"@modelcontextprotocol/server-filesystem",
				"/path/to/files"
			],
			"timeout": 600000
		},
		"github": {
			"type": "local",
			"command": "npx",
			"args": ["-y", "@modelcontextprotocol/server-github"],
			"enabled": true,
			"environment": {
				"GITHUB_TOKEN": "your_token_here"
			}
		}
	}
}
```

**HTTP 模式示例**：

```json
{
	"mcpServers": {
		"remote-service": {
			"type": "http",
			"url": "https://api.example.com/mcp",
			"headers": {
				"Authorization": "Bearer ${API_KEY}",
				"X-Custom-Header": "custom-value"
			},
			"env": {
				"API_KEY": "your_api_key_here"
			},
			"timeout": 1200000
		}
	}
}
```

> **注意**：HTTP 模式支持从环境变量读取配置值，使用 `${VAR_NAME}` 语法。

**自定义 API 模式示例**：

`api` 类型无需子进程或 MCP 握手，按 `endpoints` 直接发起 HTTP 请求，每个接口映射为一个 MCP 工具。该格式与 Snow APP 中「API」类型的 MCP 服务配置一致（可直接复制 APP 中的 JSON；APP 数据库格式的 `args: {cookies, endpoints}` 也能识别）。

```json
{
	"mcpServers": {
		"DeepSeekSearch": {
			"type": "api",
			"url": "https://api.deepseek.com",
			"headers": {
				"Authorization": "Bearer your_api_key_here"
			},
			"endpoints": [
				{
					"name": "WebSearch",
					"description": "网页搜索",
					"method": "POST",
					"path": "/v1/tools/search",
					"headers": {},
					"params": [
						{
							"name": "query",
							"type": "string",
							"required": true,
							"description": "搜索词",
							"location": "body",
							"defaultValue": ""
						},
						{
							"name": "count",
							"type": "integer",
							"required": true,
							"description": "结果数量",
							"location": "body",
							"defaultValue": "10"
						}
					],
					"bodyType": "json",
					"bodyTemplate": "{\n  \"query\": \"{{query}}\",\n  \"count\": \"{{count}}\"\n}"
				}
			]
		}
	}
}
```

**接口定义字段**：

- `name`：工具名（缺省为 `endpoint_<序号>`）
- `description`：工具描述，模型据此判断何时调用
- `method` / `path`：HTTP 方法与相对 Base URL 的路径，路径支持 `{{参数名}}` 占位符（按 URL 组件编码）
- `headers`：接口级请求头（与顶层 `headers` 合并，同名时接口级优先）
- `params`：参数列表
  - `location`：`query`、`path`、`header` 或 `body`，决定参数出现的位置
  - `type`：`string`、`number`、`integer`、`boolean`、`object`、`array`
  - `required`：是否必需（有 `defaultValue` 时模型可省略）
  - `defaultValue`：默认值，调用方未提供时自动补上
- `bodyType`：`none`、`json`、`form`、`multipart` 或 `raw`
- `bodyTemplate`：请求体模板，`{{参数名}}` 会被替换（`json` 中单独成串的占位符保留原始类型，缺失的可选参数自动从请求体中剔除）
- `rawContentType`：`raw` 类型请求体的 Content-Type（默认 `text/plain`）

### 配置验证

保存配置文件后，系统会自动进行验证：

**成功提示**（会带上当前编辑范围名称）：

```text
项目级配置 MCP 配置保存成功！请用 `snow` 重启！
```

**错误提示**：

```text
JSON 格式无效，修改已回退至上一个有效配置。
```

### 使用 MCP 服务

配置后需要重启 Snow CLI 使配置生效：

```bash
snow
```

启动后可以使用 `/mcp` 指令查看服务连接状态。

### 管理 MCP 服务

#### 启用/禁用服务

**方法 1：编辑配置文件**

设置 `enabled` 字段为 `false` 禁用服务

**方法 2：使用 /mcp 指令**

1. 输入 `/mcp` 打开服务面板
2. 使用上下箭头选择服务
3. 按 Tab 键切换启用/禁用状态

**注意**：

- `/mcp` 面板里的 **Tab 切换**主要面向外部 MCP 服务
- 部分内置工具服务可通过设置项 `disabledBuiltInServices` 禁用（例如 `snow-docs`）
- 例如在 `<project>/.snow/settings.json` 中写入：

```json
{
	"disabledBuiltInServices": ["snow-docs"]
}
```

内置官方文档工具（`snow-docs-list` / `snow-docs-search` / `snow-docs-get`）说明见：[官方文档工具（snow-docs）](./28.官方文档工具snow-docs.md)。

#### 重新连接服务

在 `/mcp` 面板中选择服务并按回车键可重新连接

### 故障排除

#### 1. 编辑器无法打开

**错误信息**：

```text
No text editor found! Please set the EDITOR or VISUAL environment variable.
```

**解决方案**：

设置环境变量或安装文本编辑器：

macOS/Linux:

```bash
export EDITOR=nano
```

Windows:

```cmd
set EDITOR=notepad
```

#### 2. 服务连接失败

**检查项**：

1. 命令路径是否正确
2. 是否已安装依赖包（如使用 npx 需要 Node.js）
3. 参数格式是否正确
4. 使用 `/mcp` 查看具体错误信息

#### 3. 配置不生效

**解决方案**：

1. 确认已保存配置文件
2. 重启 Snow CLI
3. 使用 `/mcp` 查看服务状态
