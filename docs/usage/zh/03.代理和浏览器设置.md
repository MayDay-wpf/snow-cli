# Snow CLI 使用文档——首次配置

欢迎使用 Snow CLI！在终端中进行 Agentic 编程。

## 代理和浏览器设置

- 启用代理时，CLI 的流量会通过自定义的端口传输

- 浏览器设置：CLI 的联网搜索功能会使用浏览器，默认会自动检测系统浏览器路径（Windows/macOS/Linux）。
- **Windows 自动检测优先级：Chrome > Edge**（Chrome 是常见安装，且能规避 Edge 联网搜索后 Alt+Tab 残留"幽灵窗口"的已知问题；未安装 Chrome 时回退到 Edge）。macOS 优先 Chrome，Linux 依次探测 `google-chrome` → `chromium` → `chromium-browser` → `microsoft-edge`。
- 想固定使用某个浏览器、默认浏览器更换了安装位置，或在 Linux 上未安装 Chromium/Chrome 时，需手动指定浏览器路径。
- 常见报错 `Failed to launch the browser process` 通常表示浏览器未安装或依赖缺失。建议先安装 `chromium` 或 `google-chrome`，并在设置里填写可执行文件路径。
- 配置文件路径：`~/.snow/proxy-config.json`，可手动设置 `browserPath`。

## Windows 已知问题：联网搜索后的"幽灵窗口"（Alt+Tab 残留）

- **表现**：在 Windows 上使用默认联网功能（联网搜索/网页抓取）后，按 `Alt+Tab` 会出现一条"联网记录"窗口条目，无法打开也无法关闭。
- **原因**：这是 Edge 浏览器的已知问题（官方尚未修复）。联网搜索本质是创建一个透明浏览器窗口，即使搜索结束、浏览器已关闭，窗口句柄仍会残留在系统的窗口列表中。
- **解决方案（推荐，系统设置）**：

  1. 打开 `设置` → `系统` → `多任务处理`
  2. 找到「对齐或按 Alt+Tab 时显示应用中的标签页」
  3. 选择 `不显示选项卡`

  此修改对多任务切换功能没有任何影响，反而会让多任务视图更干净——彻底屏蔽 Edge 残留窗口句柄出现在 Alt+Tab 中。

- **备用方案（命令行清扫）**：运行 `snow --sweep-phantom-windows` 可主动销毁残留的 Chromium/Edge 孤儿窗口句柄（仅 Windows，只会清理拥有进程已退出的窗口，不会影响正在使用的浏览器）。若清理后仍有个别残留，重启资源管理器（任务管理器 → Windows 资源管理器 → 重新启动）。
